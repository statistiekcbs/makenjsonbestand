# MakenJSONbestand tool

Tool voor het converteren iv3 Excel bestanden naar JSON.             

Met deze tool is het mogelijk om de iv3-levering van Gemeenten, Provincies en Gemeenschappelijke Regelingen om te zetten van Excel naar het JSON-format.
Op de CBS website zal telkens een nieuwe versie van dit hulpmiddel worden geplaatst indien er belangrijke wijzigingen zijn.
Er kan geen enkele garantie worden gegeven voor de juiste werking van deze tool. Er kunnen ook geen rechten aan worden ontleend.

Ga naar https://www.cbs.nl/kredo
en klik op Inzendinstructie
Daar vindt u de laatste versie van de tool: versie.2026_2
